PQC Migration Dashboard – 3 layout mockups

Sprint 1 · synthetic data · same data in all three, only the layout differs. Roles: CIO, Project Manager, Security Officer. Each first screen shows only the overall status and one headline per role; more detail appears as you click.

A · Layered Briefing

Status, then one big headline per role, then four cards. Clicking a card opens a panel with tabs; each row in a tab expands for full context.

B · Three Lanes

One column per role with one big answer. Dropdowns under each column reveal risks, blockers or alerts, and each item expands further. The disagreement on switching off fallback is one dropdown under all columns.

C · Shared Facts, Three Lenses

Status and three role cards. Tabs (Devices, Switch-off options, Timeline) start closed. Clicking a role card opens the device list filtered for that role; each device expands to show the security, project and business view side by side.
